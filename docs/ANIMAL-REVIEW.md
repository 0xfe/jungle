# Wildlife review — 5 October 2026

Reviewed against [the animal quality standard](ANIMAL-QUALITY.md). This is a source/rig/action-sheet review of the active catalog, with focused simulation and browser validation for the bear changes. It is **not** a claim that every species was watched through every behavior in a browser, or that all proposed improvements are implemented. Source pointers below are the basis for behavior findings; `npm run assets:preview` regenerates the inspectable directional/action sheets.

## Changes completed in this pass

Black bears again travel on **four legs**. Occasional upright sniffing or tree picking has explicit rise/hold/lower phases and 60–120-second recovery, rather than bipedal travel. Hind feet stay at the same coordinates while raising/lowering the torso; relaxed forepaws replace the forward-reaching walking pose. Feeding lowers and raises the head over registered transition clips. Quiet lying/resting returns; cubs can briefly paw/play near their mother and run to catch up. Adults occasionally take a short run. Mothers wait for lagging cubs, searches remain bounded, and dry-ground/obstacle checks still apply.

Nominal walking changes **0.14 → 0.30 tiles/s**, stride **0.2625 → 0.245 tiles**, giving **0.53 → 1.22 cycles/s** at unit size/pace before trip variation. Running has a separate **0.76 tiles/s / 0.43-tile stride** profile (1.77 cycles/s). Walk/run feet use their own calibrated stance/swing intervals; actual distance and body size drive playback. Individual pace, per-trip tempo, bounded acceleration/braking and varied headings remain independent. These are artistic world-scale parameters, not real-world speed measurements.

Travel poses increase **16 → 32**, headings **8 → 16**, major standing transitions **16 → 24**, and feeding transitions have 16 poses. The bake scale rises **23 → 26 pixels/model-unit** while retaining the previous world/display size. The rig adds fur texture, better muzzle/eye/paw detail, subtle weight transfer and head counter-motion. One shared rig has three distinct charcoal/brown/cinnamon palettes, stable adult size variation and parent-relative cub sizes; this is an explicit alternative to duplicating whole sprite sheets. It does not yet model individual ear shapes or seasonal coats.

Useful behavioral references: [NPS on standing to inspect/smell](https://www.nps.gov/dena/planyourvisit/bear-safety.htm), [NPS American black bear appearance and color variation](https://home.nps.gov/articles/000/american-black-bear.htm). No third-party artwork is included. The gait is an authored stylization, not motion capture or a complete anatomical simulation.

## Suggested implementation order

1. **Fix missing core activities:** giraffe browsing/gait, boar rooting, kingfisher fishing, beaver feeding, shore-bird walking/pecking. Pair each with habitat/social tests rather than adding a universal random-action switch.
2. **Remove visible pose jumps:** bison/zebra/hippo feeding and water transitions; tiger stance transitions; bird landings and perch grip. Audit footage at actual speed and inspect stop/turn foot placement.
3. **Add individual variety:** authored coat/pattern/body forms and young-adult differences, starting with animals likely to be seen in groups. Keep shared immutable frames and stable serialized traits.
4. **Improve social/environmental detail:** elephant family waiting, cub play, less mechanical fish/bird courses and pond residents; retain bounded owner territories and the current non-contact ecology.
5. **Spend extra frames where visible:** large 8-heading mammals and one-pose dives first. Do not raise every frame count blindly; calibration, posture and useful behavior matter more than raw frame totals.

## Evidence and limitations

Validation: `npm run check` passes **227 tests**, typechecking, the site build and headless snapshots. Tests cover calibrated planted feet, blocked walking/running, transition endpoints, brief standing occupancy across seeds, mother/cub recovery and play, lost support, and exact continuation of every bear action. Rig/piece tests use the delivered 26-pixel bake scale, all headings and every action frame. `npm run build:verify` verifies the built inventory and checksums.

Chrome checks covered WebGL and Canvas, normal-speed packed action previews, visible bears in seed 2718's opening, keyboard/Shift navigation, wide zoom, landscape jumps, help and a 390-pixel mobile viewport. No runtime exceptions or horizontal mobile overflow were observed. The connected-browser list was empty, so these checks used an isolated headless **Google Chrome** profile; they are not physical-phone or GPU-performance measurements. Recreate the focused review with `npm run bears:preview` and serve `artifacts/bear-motion.html`.

The atlas is **4096 × 4092 / 63.94 MiB decoded**, with 711,359 logical piece-frame references sharing 90,676 unique images. Lossless frame-index maps keep the expanded metadata around 55 MiB; this is still large and warrants future load-time work. No unrelated species was downsampled. The CPU-only bear benchmark recorded **3,714 peak visible quads**, simulation p95 **1.283 ms**, composition p95 **4.686 ms**, and quad encoding p95 **1.079 ms**. These local results include other wildlife in the scene and do not measure GPU work or establish a before/after speedup.
